# 🚀 Market Intelligence Pro

**AI-Powered Competitor Analysis & Market Gap Detection Tool**

## 📖 Overview

A comprehensive Python web application that helps product teams evaluate competing mobile apps directly from the Google Play Store, analyze customer feedback, and identify market gaps before product development begins.

## ✨ Features

- **🔍 Dynamic App Discovery**: Search Google Play by keyword (Arabic & English support)
- **📱 Multi-App Selection**: Compare 2-4 competing apps simultaneously
- **🕷️ Safe Review Scraping**: 150-300 reviews per app without memory bottlenecks
- **🗄️ Relational Storage**: Clean SQLite schema (apps + reviews tables)
- **📊 Interactive Dashboards**: Plotly charts for ratings & sentiment analysis
- ** AI-Powered Insights**: Google Gemini analyzes 1★ & 2★ reviews to surface:
  - Top recurring bugs/complaints
  - Missing features users want
  - Strategic recommendations
- **📥 Multi-Sheet Excel Export**: Professional downloadable reports
